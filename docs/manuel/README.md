# SIF – Manuels d’utilisation (Client)

Ce dossier regroupe les guides exhaustifs destinés au client final. Chaque guide détaille les écrans, menus, champs, règles métier, workflows, messages d’erreur, FAQ et bonnes pratiques.

Guides par profil
- Manuel Adhérent: `manuel-adherent.md`
- Manuel Agent: `manuel-agent.md`
- Manuel Chef de service: `manuel-chef-service.md`
- Manuel Administrateur: `manuel-admin.md`

Conventions
- « Doit » = obligatoire par la règle métier. « Peut » = optionnel selon droits/paramètres.
- Les libellés de menus sont donnés à titre indicatif et peuvent être adaptés à votre thème.
- Les données affichées sont restreintes selon le rôle: Agent (adhérents affectés), Chef de service (agence), Administrateur (global).

Support & Mise à jour
- Version du manuel: 1.0 (livrable client)
- Pour demander une mise à jour: ouvrez un ticket interne et référencez la section/écran concerné.
